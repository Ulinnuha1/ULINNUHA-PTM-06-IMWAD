# User Stories

## US-01 Login
Sebagai admin, saya ingin login agar hanya pengguna berwenang yang dapat menggunakan sistem.

## US-02 Kelola Dataset
Sebagai admin, saya ingin mengunggah dataset agar data dapat digunakan untuk proses klasifikasi.

## US-03 Preprocessing
Sebagai admin, saya ingin sistem melakukan preprocessing agar dataset siap digunakan oleh model.

## US-04 Training
Sebagai admin, saya ingin melatih model Naïve Bayes agar sistem dapat melakukan klasifikasi.

## US-05 Evaluasi
Sebagai admin, saya ingin melihat hasil evaluasi agar dapat mengetahui performa model.

## US-06 Prediksi
Sebagai admin, saya ingin memasukkan data baru agar sistem memberikan hasil klasifikasi.

## US-07 Riwayat
Sebagai admin, saya ingin melihat riwayat prediksi agar hasil proses sebelumnya dapat ditelusuri.

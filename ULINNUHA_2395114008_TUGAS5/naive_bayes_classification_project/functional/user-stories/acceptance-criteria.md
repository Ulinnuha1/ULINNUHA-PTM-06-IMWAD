# Acceptance Criteria

## US-01
- Username dan password wajib diisi.
- Login gagal jika kredensial tidak sesuai.
- Login berhasil mengarahkan ke dashboard.

## US-02
- Sistem menerima dataset dengan format yang didukung.
- Sistem menolak file yang tidak sesuai.
- Dataset berhasil tersimpan setelah validasi.

## US-03
- Data kosong ditangani sesuai aturan preprocessing.
- Atribut dan target dapat ditentukan.

## US-04
- Training tidak dapat dilakukan tanpa dataset valid.
- Model Naïve Bayes tersimpan setelah training berhasil.

## US-05
- Sistem menampilkan accuracy.
- Sistem menampilkan precision, recall, F1-score jika dapat dihitung.
- Sistem menampilkan confusion matrix.

## US-06
- Data baru dapat dimasukkan sesuai atribut model.
- Sistem menghasilkan kelas prediksi.
- Sistem dapat menampilkan probabilitas kelas.

## US-07
- Riwayat prediksi menampilkan waktu, model, input, dan hasil.

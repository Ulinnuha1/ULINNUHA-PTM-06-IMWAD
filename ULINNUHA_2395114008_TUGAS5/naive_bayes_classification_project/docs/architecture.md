# Architecture Notes

## Teknologi yang disarankan
- Frontend: HTML/CSS/JavaScript atau framework web.
- Backend: Python dengan FastAPI/Flask.
- Machine Learning: scikit-learn.
- Database: MySQL atau PostgreSQL.
- Format pertukaran data: JSON.

## Prinsip
Algoritma Naïve Bayes menjadi metode klasifikasi utama. Framework web dan database berfungsi sebagai teknologi pendukung implementasi sistem.
